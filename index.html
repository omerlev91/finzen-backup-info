FinZen Backup

FinZen Backup is a private, single-owner backup component of a personal finance application. It is not a public service: it is not offered to, and cannot be used by, other people.

What it does

Once a day, it copies already-encrypted backup archives of the owner's own application data into a folder in the owner's own Google Drive, verifies each copy, and keeps a bounded number of daily, weekly and monthly archives. Archives are encrypted before they leave the owner's server; Google Drive only ever stores ciphertext.

Google Drive access

The app requests only the drive.file permission ("See, edit, create, and delete only the specific Google Drive files you use with this app"). It cannot see or change any other file in the owner's Drive.
