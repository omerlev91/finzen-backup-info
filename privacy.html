FinZen Backup - Privacy Policy

Effective date: 25 November 2026

FinZen Backup ("the app") is a private backup tool operated by its single owner for the owner's own data. It is not available to the public.

Google user data the app accesses

  • Only files and folders that the app itself creates in the authorizing user's Google Drive, under the drive.file scope.
  • For those files: names, folder placement, size and checksums, and the file contents it uploaded.

The app does not access, read, list or modify any other Google Drive file, and does not access Gmail, contacts, calendar or any other Google service. It does not request the user's profile or e-mail address.

How the data is used

Solely to store, verify, retain and restore encrypted backup archives of the owner's own application data. The archives are encrypted on the owner's server before upload; the encryption key never leaves the owner's control and is never sent to Google.

Sharing and transfer

Google user data is not sold, shared, transferred or disclosed to any third party, and is not used for advertising, profiling, credit decisions or to train machine-learning models.

Storage and protection

The OAuth refresh token is stored only on the owner's server, encrypted at rest and readable only by an administrative process. Data in transit uses HTTPS.

Retention and deletion

The app keeps a bounded set of recent archives and moves expired ones to the Drive trash. The user can revoke access at any time at myaccount.google.com/permissions and can delete the app's folder from Google Drive.

Limited Use

FinZen Backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: use the support e-mail address shown on the Google consent screen for FinZen Backup.
